# מערכת ניהול הכנסות וגביית חובות

המערכת היא יישום סטטי הפועל כולו בדפדפן ומפורסם באמצעות GitHub Pages. קובצי
ה־Excel נקראים מקומית ואינם נשלחים לשרת על ידי קוד המערכת.

## מבנה המסכים

- **דשבורד שנה נוכחית** - סיכום הכנסות, גבייה וחובות לשנת העבודה.
- **ניהול הכנסות וגבייה** - פילוח חובות, לקוחות והפקת מסמכים.
- **חובות עבר שנגבו השנה** - חשבוניות ישנות שהותאמו בשנת העבודה.
- **דוחות הנהלה / סקירה מקיפה על שירותי מידע** - מדדים, תרשימים וטבלאות
  הנהלה הכוללים שירותי מידע בלבד.
- **דוחות הנהלה / דוח מאוחד הכנסות וגבייה בשנה הנוכחית** - הדוח המאוחד
  הקיים של הדשבורד, הזמין ישירות מהתפריט.
- **מקורות הנתונים** - מסך הכניסה הראשוני וטעינת הקבצים.
- **הגדרות תצוגה** - בחירת ערכת הצבעים המקומית.
- **אודות** - פרטי המערכת והיחידה המשרדית.

הניווט מתבצע בתוך אותו עמוד, ולכן מעבר בין המסכים אינו טוען מחדש את קובצי
המידע. כאשר מקורות החובה חסרים, נקודה קטנה מסמנת בתפריט את האפשרות
**מקורות הנתונים**.

## מקורות נתונים

| מקור | חובה | מסכים המשתמשים בו |
| --- | --- | --- |
| קובץ חובות | כן | דשבורד, ניהול הכנסות וגבייה, דוח הנהלה |
| הכנסות שנה נוכחית | כן | דשבורד, ניהול הכנסות וגבייה, דוח הנהלה |
| חשבוניות שהותאמו בשנת העבודה | לא | חובות עבר שנגבו השנה, חלקי גביית העבר בדוח ההנהלה |

הדשבורד, ניהול ההכנסות והגבייה ודוח ההנהלה נפתחים רק לאחר טעינת שני מקורות
החובה. מסך חובות העבר נפתח לאחר טעינת שלושת המקורות.

הנתונים נשמרים בזיכרון הלשונית בלבד. רענון הדף או סגירתו מחייבים טעינה מחדש.
רק העדפת ערכת הצבעים נשמרת ב־`localStorage`.

## כלל גביית חובות עבר

לשנת עבודה `Y` נכללת רשומה כאשר:

1. `תאריך התאמה`, `תאריך התאמה נטו` או `תאריך תשלום` חל בשנת `Y`.
2. תאריך הפקת החשבונית מוקדם מ־1 בדצמבר בשנת `Y - 1`.

תאריך ההפקה נקרא תחילה מהעמודה `תאריך מסמך`, ואם היא חסרה - מ־`תאריך
רישום` או `תאריך ערך`.

הכלל מיושם בפונקציה `getEligibleHistoricalRows`. שינוי שנת העבודה מחשב מחדש
את שנת ההתאמה, תאריך הסף, רשימת שנות המקור וכל הסיכומים.

## פונקציות מרכזיות

- `navigateToScreen` - ניווט, נעילת מסכים ושמירת הנתונים בין המעברים.
- `updateDashboardAccessState` - עדכון זמינות המסכים ומצב מקורות הנתונים.
- `parseRevenueRows` - parser משותף להכנסות השנה ולחשבוניות העבר.
- `processHistoricalRevenueExcel` - טעינת מקור הנתונים האופציונלי.
- `renderHistoricalCollections` - הפעלת המסננים ובניית המדדים והטבלאות.
- `renderHistoricalDetailRows` - סינון מקומי של רשימת החשבוניות לפי שם או
  מספר לקוח, בלי לשנות את המדדים, הטבלאות והגרפים שמעליה.
- `printHistoricalBreakdown` - הפקת פירוט החשבוניות המרכיבות שורת שנה או
  שורת סקטור בטבלאות הסיכום.
- `printHistoricalSummaryReport` - הפקת שתי טבלאות הסיכום של חובות העבר.
- `getManagementReportData` - בניית נתוני דוח ההנהלה לשירותי מידע בלבד.
- `renderManagementReport` - הצגת מדדי, תרשים וטבלאות דוח ההנהלה.
- `printManagementReport` - הפקת גרסת הדפסה משרדית לדוח ההנהלה.
- `getEligibleHistoricalRows` - כלל ההכללה העסקי של חשבוניות עבר.

בדוח ההנהלה, טבלאות החובות הפתוחים כוללות רק חובות ששנת הפירעון שלהם מוקדמת
משנת העבודה. דוח ההדפסה מחולק לעמוד תמונת מצב, עמוד חובות פתוחים ועמוד חובות
עבר שנגבו בשנת העבודה. הדוח מודפס לאורך, וכל עמוד חדש מתחיל לאחר השלמת
הטבלאות והתרשימים של החלק הקודם.

חתכים לפי שנים מוצגים בטבלה ובגרף עמודות, כדי לשמור על הרצף הכרונולוגי.
חתכים לפי סקטורים מוצגים בטבלה ובגרף טבעת, כדי להמחיש את חלקו היחסי של כל
סקטור. טבלאות החוב וגביית העבר כוללות עמודות „מספר לקוחות”, „מספר
חשבוניות” וסכום כספי, וכן שורת סך הכול. בטבלאות לפי שנים, מספר הלקוחות
בשורת הסה״כ הוא מספר הלקוחות הייחודיים בכל הטבלה ולא סכום שורות השנים.

בדוח שירותי המידע, החלק „חובות עבר שנגבו בשנת העבודה” מוצג במסך ובדוח
המודפס רק לאחר טעינת קובץ החשבוניות שהותאמו בשנת העבודה.

## עקרונות לשינוי עתידי

- אין לשנות את חישובי הדשבורד או החובות ללא בדיקת השוואה מול הקובץ הקיים.
- מקור נתונים חדש יישמר במערך נפרד ולא ישנה מדדים קיימים שלא משתמשים בו.
- יש לנקות טקסט שמקורו בקובצי Excel לפני שילובו ב־HTML.
- כל כלל התלוי בשנה צריך להתבסס על `CURRENT_YEAR` ולא על שנה קשיחה.
